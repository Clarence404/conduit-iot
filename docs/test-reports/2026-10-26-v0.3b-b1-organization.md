## 3. 测试过程中发现并修复的问题

1. 组织资源更新时，编码唯一性查询最初没有排除当前记录，导致保持原编码的正常更新被误报 409。已在四类资源的查询中按 id 排除自身，专项与完整回归均通过。
2. 修复后第一次专项复验失败：Maven 进程实际使用 Java 17，无法加载 Java 21 编译的测试类（class file 65/61）。该次属于测试环境失败，没有执行到业务测试；显式设置 `JAVA_HOME` 和 `Path` 后重跑通过。此失败未静默删除。
