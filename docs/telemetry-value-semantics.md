# 遥测值全局语义：缺测与零值

本约定适用于设备上报、编解码、校验、PostgreSQL/Redis/InfluxDB 数据访问、API、聚合计算、最新值、曲线、导出、模拟器以及后续规则和告警。遥测数值的缺测与零值必须全链路区分。

## 基本规则

| 情况 | 语义 | 展示 |
|---|---|---|
| `null` 或该测点在该时刻缺省 | 该测点该时刻没有上报数据；不代表设备从未上报 | 无数据/缺测；曲线留空 |
| 数值 `0` | 已上报且有效的零值 | 正常显示 0，参与计算和曲线 |
| 布尔 `false`、枚举值 `0` | 有效状态值 | 显示相应状态，不能当作缺测 |
| 校验失败、NaN、Infinity | 无效数据 | 拒绝并按校验契约记录；不能改写成 0 |
| 查询失败或存储不可用 | 未能取得结果 | 明确错误状态；不能伪装成无数据或全零 |

以上 `null` 规则针对遥测值；名称、单位、归属等元数据的 null 仍按各字段契约解释。计数结果 0 表示已成功统计且数量为零，不等于遥测零值；统计失败不能用 0 代替。

## 全链路要求

- 上报遗漏测点或显式 null 均不产生零值样本。显式 null 的接收/拒绝沿用编解码和校验契约，不要求数据库写入 null 占位，更不能转换成 0。
- 禁止用 `value || 0`、`value ?? 0`、`Number(null)`、`COALESCE(value, 0)` 或类似逻辑给缺测赋零；检查缺测不能用 truthy 判断丢弃 0/false。
- 最新值保留最后一次有效上报的值及其原始时间戳；后续报文缺少该测点不能刷新其时间戳或把它归零。最新值不代表当前时刻有上报；是否陈旧须另行标记。
- 原始历史允许只返回实际样本，但不能把省略点解释为 0；曲线若需判定两样本间是否缺测，必须有明确的采样周期/缺测阈值，不能自行把任意时间间距当作连续数据。
- 聚合只计算有效非空样本，0 正常参与 avg/min/max/sum/count。无有效样本的桶结果为 null/缺测（包括 sum），不能返回数值 0；有效样本数量可返回 count=0。
- 曲线已知缺测处断线，折线、阶梯线与 min/max 波动带均适用；禁止补零、默认前值延续或插值。若未来提供插值功能，须由用户显式选择并标记估算值，不能混同原始上报。
- 导出保留缺测语义（JSON null、CSV 空单元格或明确约定的缺测标记），真实 0 原样导出。
- 模拟器可以上报业务含义明确的 0，例如夜间辐照度和光伏功率；模拟断连/缺测时应停止对应上报，不能发送 0 冒充缺测。已有零值不得仅凭值为 0 批量改成 null。

## 当前静态审查与待修复项（2026-10-26）

- `DayCurves.sun` 与 `PointGenerator.solar` 明确在夜间生成 0；截图的夜间辐照零线与该模拟逻辑一致，不能据此认定是缺测补零。
- `HistoryQueryBuilder` 未使用 COALESCE 补零；现已在 `HistoryService.queryAggregate` 按同一桶宽/1970原点补齐 `[from,to)` 覆盖的时间桶：AGG 空桶为 `[ts,null,null,null]`，LAST 空桶为 `[ts,null]`。真实0/false保留，不向数据库写入虚构样本。
- `historyChart.ts` 的 `max-min` 已增加空值保护；折线、状态线、波动带及迷你趋势线均保留 null 且显式不连接缺点，tooltip 显示无数据。全 null 序列显示「该时段没有数据」。
- 原始历史的整段不上报需要先确定采样周期/缺测阈值契约，不能凭现有稀疏样本准确推断每个缺失时刻。与聚合空桶处理分别设计。
